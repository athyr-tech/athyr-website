Why Athyr

📦

Single Binary

No external dependencies. Deploy anywhere with a single executable. Zero configuration required.

🔌

Language Agnostic

Write agents in any language. Athyr handles orchestration, messaging, and state management.

⚡

LLM Gateway

Multi-backend routing with circuit breakers, automatic retry, and failover built in.

🧠

Stateless Agents

Agents remain stateless. Athyr manages memory and state externally for true scalability.

📡

Agent Registry

Automatic discovery and registration. Agents find each other seamlessly through the runtime.

🔒

Edge Ready

Lightweight enough to run on edge devices. Perfect for IoT and distributed deployments.

Quick Start

# Install Athyr
curl -sSL https://athyr.tech/install.sh | sh

# Start the server
athyr serve

# gRPC: localhost:9090
# HTTP: localhost:8080

# Connect agents via SDK
go get github.com/athyr-tech/athyr-sdk-go
